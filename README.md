# zavet-date

Русские даты, календарь и склонение интервалов («5 минут назад») для языка **Завет**.

## Установка

```bash
zavet подключить дата
```

## Использование

```zavet
приими дата из "дата"

возгласи(дата.формат_рус(ничего, истина))
возгласи(дата.назад(время.сейчас() - 300))
```

## Тесты

```bash
zavet тесты.молитва
```
